# 前後台網頁架構

> 匯出日期：2026-10-14（依 `main` 分支 `f1dbb78` 原始碼整理）

| 端 | 目錄 | 對象 | 本機網址 |
|---|---|---|---|
| 前台（使用者端，PWA） | `apps/member` | 一般會眾 | http://localhost:5173 |
| 後台（管理控制台） | `apps/console` | 同工（系統管理員／據點管理員／查察員） | http://localhost:5174 |
| 共用套件 | `packages/shared`（`@church/shared`） | 兩端共用 | — |
| API | `backend`（Express + Supabase） | 兩端共用 | http://localhost:3001 |

兩個前端都是單頁應用，**不使用 router 套件**：前台以 state 切換分頁（支援 `?tab=` 捷徑），後台以網址 hash（`#page-id`）記錄目前頁面。

---

## 一、前台（apps/member）

### 1. 進入流程

```text
載入中
 ├─ 未登入 ──────────────→ LoginPage
 ├─ 帳號資料載入失敗 ────→ 錯誤卡（重新讀取／登出）
 └─ 已登入
     ├─ 尚未選據點 ──────→ BranchPickerPage（選擇據點，存在 localStorage）
     └─ 已選據點 ────────→ 主畫面（底部導覽 4 個分頁）
         └─ 首次登入（未填姓名）→ 強制開啟 ProfileModal 填寫基本資料
```

### 2. 頁面樹

```text
主畫面（AppHeader + BottomNav）
├─ 首頁 home ─────────── HomePage
│   ├─ InstallBanner（PWA 安裝提示）
│   ├─ 據點公告列表 → Sheet：公告內容
│   ├─ 牧區借用資格／違規點數 → Sheet：違規與扣點明細
│   └─ 借用規則
├─ 預約 booking ──────── BookingPage（步驟式表單）
│   ├─ 步驟 1 選擇借用類型：一般借用／婚禮／重要活動／取消或異動
│   ├─ 步驟 2 借用人資料
│   ├─ 步驟 3 選擇日期與時段
│   ├─ 步驟 4 選擇場地（婚禮、重要活動可複選）
│   ├─ 步驟 5 用途說明
│   ├─ 步驟 6 確認送出
│   └─ （取消或異動）選擇要更動的預約
├─ 檔期 weekly ──────── WeeklyBulletin（shared，含婚禮與重要活動）
│   └─ 點空檔 → 帶入日期與場地，跳到「預約」
└─ 我的 me ──────────── MePage
    ├─ 個人資料 → ProfileModal
    ├─ 切換據點 → 回到 BranchPickerPage
    ├─ 登出
    └─ 借用紀錄 RecordsPage
        ├─ 分段：即將到來／待清潔歸還／已完成／未通過（可依場地篩選）
        ├─ Sheet：預約明細
        ├─ 場地歸還檢查 → CleanupModal
        └─ 故障回報 → IssueReportPage（隱藏分頁 issues，返回「我的」）
```

- 全域元件：`StatusToast`（操作結果）、新版本提示列（`useAppUpdate`）。
- `?tab=records` 舊捷徑會導向「我的」。
- `IssueHistoryPage.tsx` 目前沒有被任何頁面引用。

### 3. 程式結構

```text
apps/member/
├─ public/
│   ├─ sw.js、sw/config.js、sw/services/cache-manager.js   # Service Worker
├─ src/
│   ├─ App.tsx              # 進入流程、分頁切換、資料載入
│   ├─ navigation.ts        # 分頁定義與 ?tab= 解析
│   ├─ pages/               # Home / Booking / BranchPicker / Login / Me / Records / IssueReport / IssueHistory
│   ├─ components/          # AppHeader / ProfileModal / CleanupModal / StatusToast
│   ├─ hooks/               # useBooking / useProfile / useIssueReport / useOnlineStatus
│   ├─ features/pwa/        # InstallBanner、installPrompt、useAppUpdate
│   ├─ services/            # BookingDraftService、PwaService
│   ├─ repositories/        # IndexedDB（預約草稿）
│   └─ ui/                  # BottomNav、Button、Field、ListRow、SegmentedControl、Sheet、Skeleton、StatStrip、StatusPill…
```

## 二、後台（apps/console）

### 1. 進入流程

```text
載入中
 ├─ 未登入 ─────────────→ Login（shared）
 ├─ 帳號資料載入失敗 ───→ 錯誤卡
 ├─ 角色為 user ────────→「此帳號沒有後台權限」
 └─ 同工
     ├─ 未選據點 ───────→ 據點選擇卡片（指派到單一據點的管理員／查察員自動鎖定，不可切換）
     ├─ 無該據點權限 ──→「沒有權限」提示
     └─ 有權限 ─────────→ AdminPanel（桌機左側導覽／手機底部導覽）
```

### 2. 導覽與頁面

導覽與權限唯一來源：`apps/console/src/navigation.ts`。網址 hash 即頁面 ID，無效或無權限時回到 `#overview`。

角色：`system_admin` 系統管理員、`admin` 據點管理員、`inspector` 查察員。
下表「全部」= 三種角色；「同工」= system_admin + admin。

| 分類 | 頁面（hash） | 元件 | 可見角色 | 資料來源 |
|---|---|---|---|---|
| 總覽 | 今日總覽 `#overview` | `OverviewPage` | 全部 | `useConsoleTodos`（待辦數字＋今日借用） |
| 預約 | 預約審核 `#bookings-review` | `BookingsTab`（mode=bookings）＋ `ConflictBoard` | 同工 | `GET /api/admin/bookings` |
| | 表單匯入紀錄 `#bookings-form-intake` | `FormIntakeTab` | 同工 | `GET /api/admin/form-intake` |
| | 試算表匯入 `#bookings-sheet-import` | `SheetImportPage` | 同工 | `POST /api/rooms/import-sheets` |
| 檔期 | 週看板 `#schedule-week` ⇔ | `WeeklyBulletin`（shared） | 同工 | `GET /api/bookings/weekly` |
| | 婚禮與重要活動 `#schedule-events` | `SpecialEventsPage`（shared） | 同工 | `GET /api/bookings/special` |
| | 平面地圖 `#schedule-map` ⇔ | `FloorMap` | 同工 | `GET /api/bookings/by-date`、`GET /api/bookings/now`、`PUT /api/rooms/:id/polygon` |
| 現場 | 清潔稽核 `#onsite-cleaning` | `BookingsTab`（mode=cleaning）＋ `AssignCleaningModal`、`AdminInspectionModal` | 全部 | `GET /api/admin/bookings` |
| | 門鎖密碼 `#onsite-locks` | `BookingsTab`（mode=lock-management） | 同工 | `GET /api/admin/bookings`、`POST /api/bookings/:id/send-password` |
| | 故障回報 `#onsite-issues` | `IssuesTab` | 全部（查察員沒有管理權限，`canManage=false`） | `GET /api/issues` |
| 會員 | 違規記點 `#members-violations` | `ViolationsTab` | 同工 | `GET /api/admin/violations` |
| | 公告 `#members-announcements` | `AnnouncementsTab` | 同工 | `GET /api/announcements` |
| 設定 | 場地配置 `#settings-rooms` | `RoomsTab` | 同工 | `GET /api/rooms` |
| | 公共空間 `#settings-public-spaces` | `PublicSpacesTab` | 同工 | `GET /api/public-spaces` |
| | 智慧裝置 `#settings-devices` | `TuyaTab` | 同工 | `GET /api/tuya/devices-status`、`POST /api/tuya/control` |
| | 使用者角色 `#settings-users` | `SuperAdminPanel` | 僅 system_admin | `GET/PUT /api/users/roles` |

⇔ 標記為寬版頁面，進入時自動收合側邊欄。

**手機導覽**：底部直接顯示「總覽、預約、檔期、現場」，「會員、設定」收進「更多」。各分類會顯示待辦徽章數字。

### 3. 程式結構

```text
apps/console/src/
├─ App.tsx              # 登入、角色檢查、據點選擇
├─ AdminPanel.tsx       # 導覽框架、依頁面載入資料、renderPage
├─ navigation.ts        # 分類／頁面／角色權限定義
├─ FloorMap.tsx         # SVG 平面地圖
├─ SuperAdminPanel.tsx  # 使用者角色管理
├─ pages/admin/         # Overview / Bookings / ConflictBoard / FormIntake / SheetImport / Issues / Violations / Announcements / Rooms / PublicSpaces / Tuya
├─ components/          # AppHeader / ProfileModal / AssignCleaningModal / AdminInspectionModal
├─ hooks/               # useConsoleTodos / useProfile / useEscapeKey
└─ domain/              # bookingStatus（狀態判定）
```
